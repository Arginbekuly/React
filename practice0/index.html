Task 5: Shallow vs Deep Copying

1. Исходный код: 
// Поверхностная копия:
const copy = { ...original };
// Глубокая копия вложенного объекта:
const deepCopiedUser = { ...user, address: { ...user.address } };
2. Результат работы:
3. Пояснение:
Обычный {...original} делает только поверхностную копию. Если у нас внутри есть еще один объект (как address), то при обычном спреде он будет ссылаться на ту же память. Поэтому для адреса я сделал еще один спред address: { ...user.address }, чтобы изменения в копии не меняли оригинал.

    return function() {
        count++;
        return count;
    };
}
const count2 = createCount();
2. Результат работы:
3. Пояснение:
Замыкание — это когда внутренняя функция запоминает переменные из внешней функции, даже когда внешняя уже завершила работу. Поэтому когда мы вызываем count2() несколько раз, переменная count не сбрасывается, а постоянно увеличивается.
